# YIQI XP｜億柒懷舊系統 v0.1.9

## 本次更新
- 將即時通模組改名為 **YIQI Talk｜億柒懷舊通**。
- 主題新增 **水藍／粉紫／質感黑** 三種可切換配色。
- **預設主題為水藍**，重新啟動或關機後再開機會恢復為水藍。
- 桌面上的即時通圖示、視窗標題、通知標題與聊天視窗名稱同步改為 YIQI Talk。
- 登入畫面改為較不近似舊即時通的自有風格：聊天泡泡圖形 + YIQI Talk 字樣。
- 保留原本可用功能：開關機音效、三首原創音樂、好友加入通知、刪除／略過好友、桌面拖曳、重新開機還原。

## 使用說明
1. 保持原本 GitHub 專案與網址不變。
2. 上傳本版 `index.html` 覆蓋專案根目錄舊檔。
3. Commit changes 後等待 GitHub Pages 更新。

## 驗收重點
- 開啟桌面上的 **YIQI Talk**。
- 在登入畫面與好友清單切換 **水藍／粉紫／質感黑**。
- 關閉聊天視窗再重新開啟，確認主題仍沿用本次開機選擇。
- 重新啟動模擬系統後，確認主題自動恢復為 **水藍**。

## 注意
這是純網頁懷舊模擬，沒有連線任何真實即時通服務，也不會蒐集真實帳號密碼。
