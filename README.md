# YIQI XP｜億柒懷舊系統 v0.4.1

## 本次更新
- 控制台的「YIQI XP 草原桌布」已改為真正帶有 YIQI XP 字樣的草原圖片。
- 針對手機直式另行調整桌布構圖，避免字樣被桌面圖示遮住。
- 桌布已直接內嵌於 index.html；部署時只需上傳這一個檔案。
- 其他桌布、YouTube 播放器、聊天、待命、重新開機還原規則都不變。
- 保留原本 apple-touch-icon.png 圖示，未變更其他網頁。

## 使用方式
1. 把 index.html 覆蓋上傳至 GitHub 專案根目錄。
2. 在 YIQI XP 桌面開啟「控制台」。
3. 進入「桌面背景」，選擇「YIQI XP 草原桌布」。
4. 模擬重新開機後，桌布仍會依照原規則回到預設「青空草原」。

## 關於圖片
ZIP 中另外附上橫式、直式 WebP 圖片供備份使用，網站主程式本身已包含它們，不須另外部署。
