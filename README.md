# YIQI XP｜億柒懷舊系統 v0.1.6

## v0.1.6 音樂播放器修正
- 修復三首曲目聽起來相同、按下一首沒有立即換音的問題。
- 「午後藍天」為 116 BPM 輕快草原三角波旋律。
- 「像素漫遊」為 176 BPM 快節奏 8-bit 方波旋律。
- 「夜色星光」為 72 BPM 舒緩正弦波夜曲。
- 播放中按「下一首／上一首」會立即停止舊旋律、開始新曲；下拉選單同樣有效。
- 暫停狀態選曲不會自動播放，重新按播放會從新曲開始。
- 重新開機仍恢復第一首預設曲目；音量及開關機獨立音效保留。
- 這三首是**原創的合成電子旋律**，不是 MP3 或商業歌曲。

## 前版功能仍保留
- 保留 v0.1.4 開機／關機獨立原創音效、音量控制、模擬音樂播放器。
- Messenger 虛擬好友可以「略過」、「恢復顯示」、「刪除」，重新開機時還原。
- 模擬好友邀請、好友上線、新訊息的 Windows XP 風格桌面通知。
- 叮咚震動後，虛擬好友會自動回覆「我來了我來了🏃 再震就要腦震盪了🥹」。
- 手機直式桌面超出畫面寬度可左右滑動。
- 長按桌面圖示約 0.2 秒可拖曳，重新開機恢復原位。
- iPhone 主畫面模式補上狀態列樣式設定和深色背景；iOS 頂部系統狀態列仍受系統控制，不能保證完全消除。
- 網頁標題改為「YIQI XP｜億柒懷舊系統」。

## 操作驗收
- 進 Messenger 測試略過／恢復／刪除好友。
- 在聊天視窗按「叮咚震動」確認收到趣味回覆。
- 回桌面查看好友邀請和留言通知。
- 長按並拖曳圖示；直式畫面可左右滑動。
- 待命後喚醒應保留變更；重新啟動後應恢復預設好友及圖示排列。

本站是純前端 Windows XP 風格模擬，不是真正 Windows 系統，也沒有真人通訊功能。音效均為程式產生的原創模擬音效，不含 Windows 原版聲音或商業歌曲。
