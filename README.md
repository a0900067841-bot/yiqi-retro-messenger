# YIQI XP｜億柒懷舊 Messenger v0.7.4

## 本次修正：個人資料備份匯入防護
- 在確認覆蓋前先檢查 JSON 備份的資料夾、文件、回收筒、安裝程式及捷徑資料。
- 防止 null 欄位、缺少系統資料夾、重複 ID、循環資料夾、無效文件等損壞或非本系統格式的資料被當成有效備份。
- 無效備份直接拒絕匯入，保留目前資料，不開啟覆蓋確認、不寫入瀏覽器儲存空間。
- 正常由 v0.7.3 匯出的備份仍可匯入。
- 保留原本 Windows XP 模擬桌面、YIQI Talk、18 類別瀏覽器、小畫家及重新開機保存規則。

## 部署方式
將本 ZIP 內的 index.html，上傳至既有 GitHub 儲存庫根目錄，覆蓋原本同名檔案。其餘圖片及圖示未改。

## 測試與限制
透過隔離 Chromium 模擬瀏覽器驗證（手機直式與電腦尺寸），未修改 GitHub 正式站。
請在 iPhone Safari 實際操作前，先匯出一份目前的個人資料備份；切勿使用唯一一份真實重要資料測試覆蓋匯入。
