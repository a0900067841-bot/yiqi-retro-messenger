# YIQI XP｜億柒懷舊系統 v0.1.4

## 新增：開關機獨立音效
- 登入桌面播放原創「開機」上升和弦音效。
- 關機與重新啟動先播放另一段原創「關機」下降和弦音效，重開後再播放開機音效。
- 工作列右下角喇叭可獨立開關開機、關機、一般提示音、播放器電子音樂，並分別試聽開關機音效。
- 音量滑桿及總靜音僅控制網頁聲音，不控制 iPhone 或電腦的實際系統音量。
- 音效為本網頁即時產生的原創旋律，**不是 Windows XP 原廠音效**，不含歌曲或 MP3。
- 設定屬於模擬環境，重新啟動／關機後再次開機將恢復出廠預設，待命不還原。
