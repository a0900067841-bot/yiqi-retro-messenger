# YIQI XP｜億柒懷舊系統 v0.1.7

## 新增：復古即時通登入畫面

- 開啟 Messenger 時先顯示復古紫色 YIQI 即時通登入介面，風格參考昔日 Yahoo! 奇摩即時通，但不冒用 Yahoo 原版商標。
- 可修改模擬登入帳號，預設 yiqi_guest；密碼欄位僅顯示假密碼，不可輸入真實密碼。
- 支援「記住模擬帳號」、「關閉後再次開啟自動登入」、「隱藏模式登入」。設定僅在本次開機有效。
- 登入後開啟原本模擬好友清單及聊天，加入好友、刪除、略過、叮咚震動等功能不變。
- 可從好友清單按「登出即時通」，再次開啟登入畫面。
- 未登入即時通前不會出現虛擬好友的上線、新訊息與邀請通知。
- Windows 重新開機或關機後再次開機，模擬帳號、好友變更、訊息和設定一律恢復預設。
- 原本的獨立開關機音效、音量、三首不同原創電子旋律、桌面拖曳與左右滑動都保留。

## 操作說明

1. 按電源啟動 YIQI XP，進入 Windows 模擬桌面。
2. 點「Messenger」，會看到經典紫色登入畫面。
3. 需要時可修改帳號名稱，無須也不能輸入真實密碼；點「登入(N)」。
4. 登入後選擇虛擬好友聊天；點「登出即時通」可返回登入畫面。
5. 按 Windows 開始選單 → 重新開機，將恢復預設的即時通登入狀態。

## 限制與安全

本系統只模擬即時通登入，沒有任何真正 Yahoo 或其他外部帳號認證，不收集、不驗證、不傳送真實密碼。密碼欄位是無法編輯的假密碼展示。
