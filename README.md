# YIQI XP｜億柒懷舊系統 v0.1.8

## 本版新增
- 即時通登入後可切換「線上／忙碌／離開／隱身」，僅為模擬狀態。
- 好友清單新增搜尋功能，支援手機輸入即時篩選。
- 模擬好友新訊息顯示未讀數；打開聊天後自動標示已讀。
- 回覆前顯示「正在輸入…」，登出或重新啟動即取消尚未送出的模擬回覆。
- 刪除、略過好友時也清理對應未讀資訊；開機恢復預設。
- 保留 v0.1.7 的紫色即時通登入、叮咚震動、懷舊桌面、三首電子旋律與開關機獨立音效。
